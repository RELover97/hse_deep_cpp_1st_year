# Семинар "Наследование. Динамический полиморфизм"

## Постановка задачи

У нас есть система финансового анализа. Она получает операции:

- доход
- расход
- перевод

Для каждой операции нужно:

- хранить сумму
- хранить описание
- рассчитывать её влияние на итоговый баланс
- выводить информацию

## Первичное решение

В первом приближении мы захотим написать свой класс `Operation` (см. `main.cpp`). Но в чём тут нюанс: 
для каждой операции тот или иной метод должен работать по-своему, то есть должна быть своя реализация
того или иного метода для той или иной операции. Тут нам помогает один из принципов объектно-ориентированного программирования (в С++, в частности) - наследование, которое выражает отношение между классами "is-a", то есть объект производного класса является объектом базового класса.
